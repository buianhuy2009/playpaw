# PawPlay Project Context

## Project Summary
PawPlay is an interactive sensory web application designed specifically for domestic cats, calibrated to feline visual biology (dichromatic vision ~450nm/550nm, 70-100Hz flicker fusion rate), capacitive paw touch physics, and robust browser tab defense (preventing accidental tab closure or browser gesture triggers).
